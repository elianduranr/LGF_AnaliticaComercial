# DVC - Proyecto despliegue LGF

El EDA corre contra las bases crudas locales completas, pero esas bases no se
suben por peso y sensibilidad operativa. Para la primera entrega se versiona
con DVC una muestra reproducible:

- `datos/raw/ventas_facturadas_muestra_2021_2026.csv`

Remoto local configurado:

- `dvc_storage`

Este remoto permite demostrar el flujo DVC sin cargar la base completa al
repositorio Git.
